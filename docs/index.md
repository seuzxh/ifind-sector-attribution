# iFinD 行业归因与板块强度检测系统

基于同花顺 iFinD API 的量化**行业归因 + 板块强度检测**系统：自动判定"哪只股票被哪个概念带涨"、"当前哪个板块最强"，并提供盘中实时可视化看板与飞书定时推送。**仅处理 A 股**（沪深北交易所）。

## 系统目标

1. **板块强度检测**——三维评分（涨幅强度 / 上涨广度 / 相对强度）+ Z-score 标准化，1d / 5d / 20d 多周期融合，回答"现在谁最强"。
2. **个股归因**——L1 权重法分解个股涨幅对各概念的贡献，回答"这只票是被谁带涨的"。
3. **盘中实时监控**——分时数据驱动的多 Tab 看板（3s 轮询、时间条回看、播放回放），从 9:15 集合竞价到收盘全覆盖。
4. **强势归类与推送**——自然语言选股（iFinD MCP）后按自选分组 / 监控板块归类，并在交易日 4 个时刻自动推送飞书。

## 功能全景

```
数据层    iFinD 5 接口（字典/成分股/日K） ─ kline-fetcher 分时 ─ iFinD MCP 选股
计算层    板块强度(三维+多周期) ─ L1 个股归因 ─ 四维成分股评分 ─ 轮动 LLM 分析
服务层    FastAPI REST（25 端点） + Vue 3 SPA（7 Tab 看板）
交付层    浏览器看板 ─ 飞书定时推送（9:33 / 9:45 / 10:00 / 14:30）
```

看板 7 个 Tab：📊 板块强度监控 · ⭐ 自选分组监控 · ⚡ 集合竞价 · 🎯 自选强势归类 · 🌐 全市场强势归类 · 🔮 板块轮动分析 · 🛠️ 监控板块管理。

## 5 分钟看懂核心概念

- **双概念编码体系**：行业码（700xxx / 881xxx）与概念板块码（885xxx / 886xxx）是两套体系，`init` 的"概念板块全集补全"把两者打通，归因 JOIN 才能工作。
- **两条数据链路**：`daily`（盘后日K → 入库 → 多周期融合）与 `realtime`（分时序列 → 内存切片 → 四维评分），口径不同、互不干扰。
- **永久缓存表**：`stock_concept_map` / `concept_members` 不传日期默认取最新快照，与同步日期解耦。
- **监控板块规则**：管理页勾选持久化 + 最新成分股数 10~500 双重过滤，越界板块自动失效。
