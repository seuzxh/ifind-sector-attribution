# 交互指南

本文面向看板的日常使用者，逐一说明 7 个 Tab 看什么、怎么操作。看板是 Vue 3 单页应用，访问 `http://<服务器>:8000` 进入，顶部 Tab 切换，各页状态互不干扰（切换后回来数据还在）。

## 总览：7 个 Tab

| Tab | 回答的问题 | 数据源 |
|---|---|---|
| 📊 板块强度监控 | 现在哪个板块最强？ | 分时实时 / 历史收盘 |
| ⭐ 自选分组监控 | 我的自选分组里谁在涨？ | 同上（分组换成自选） |
| ⚡ 集合竞价 | 今天集合竞价哪些板块抢筹？ | 9:15~9:25 竞价分时 |
| 🎯 自选强势归类 | 全市场强势股落在我哪些自选分组？ | REST 智能选股 + 自选交集 |
| 🌐 全市场强势归类 | 强势股集中在哪些监控板块？ | REST 智能选股 + 勾选板块 |
| 🔮 板块轮动分析 | 热点在板块间如何轮动？ | LLM 流式分析 |
| 🛠️ 监控板块管理 | 监控哪些板块？ | 勾选持久化 |

## 通用：实时链路的交互节奏

三个概念决定了看板的"手感"：

1. **3 秒轮询**：页面每 3 秒向后端要一次最新切片；状态栏的"刷新 HH:MM:SS"一直在走，说明页面活着。行情本身是分钟级粒度——时刻只在新分钟数据到达后才变化，两次刷新看到同一时刻是正常的。
2. **时间条**：拖动滑块到任意时刻（如 9:50）即可回看当时的板块排名；拖动后自动暂停跟随最新，点"回到最新"恢复。
3. **▶ 播放**：按 1.5x / 2x / 4x / 8x 速度逐分钟自动推进时间条，像动画一样回放全天轮动。

非交易时段打开看板：显示最近交易日的全天数据，时间条照常可拖、可播。

## 📊 板块强度监控

监控对象 = 「监控板块管理」勾选且成分股数 10~500 的概念板块。

- **页面布局**：顶部统计栏（股票数 / 涨跌家数 / 涨停数）→ 时间条 → Top10 强势板块 + Bottom10 弱势板块 → 下方各板块成分股卡片。点击板块行可高亮它的成分股卡片。
- **实时 / 历史模式切换**：实时模式走分时数据；历史模式选日期读收盘数据（秒级响应）。
- **成分股排序**：卡片默认展示综合分前 10；点击表头（涨幅 / 涨速 / 加速 / 开盘至今 / 综合分）后端在**全量有效成员**上重新排序再返回前 10——排序永远基于全量，不是只排可见的 10 只。
- **四维评分**：综合分 = 涨幅 0.4 + 涨速 0.2 + 开盘至今涨幅 0.2 + 涨停 0.2（各分量 Z-score 标准化）；涨速加速（▲加速 / ▼减缓）仅展示不进综合分。

## ⭐ 自选分组监控

与板块看板同款功能，只是"分组"换成你导入的自选股分组（同花顺 custom_block 导出）。

- **持仓金色标注**：名为 `CC` 的分组（可在 `config.HOLDING_GROUP_NAME` 改）视为持仓分组。含持仓股的分组会金色高亮（排行表行 + 卡片描边 + 持仓徽章），一眼看出哪些主题踩中了持仓。
- 分组更新后重导即可：`python main.py import-groups`（幂等）；页面检测到 JSON 变更也会自动重导。

## ⚡ 集合竞价

9:15~9:25 专用。此阶段还没有成交，页面基于竞价逐点 `ref_price`（约 3 秒一点）推算涨幅：

- 9:20 前可撤单、9:20~9:25 不可撤单，后段价格可信度更高（前端有窗口提示）。
- 用途：开盘前预判哪些板块被抢筹，为 9:30 后的板块监控做心理准备。

## 🎯 / 🌐 强势归类（两页同款，范围不同）

输入一句自然语言选股条件（如 `涨幅大于7%并且小于12.1%；未涨停；非ST`），后端调 iFinD REST `smart_stock_picking` 全市场选股，然后：

| 页面 | 归类范围 | 适合回答 |
|---|---|---|
| 自选强势归类 | 与自选分组取交集，按自选分组归类 | 强势股有没有落进我的池子 |
| 全市场强势归类 | 按管理页勾选板块归类 | 强势股集中在哪些主题 |

- 两页各有 4 组预置条件（对应 9:33 / 9:45 / 10:00 / 14:30 的推送条件），也支持自定义：输入后可保存到浏览器、重命名、删除。
- 结果按分组手风琴展示：命中数 / 覆盖率 / 平均涨幅 / 命中个股。一股属多组时各组各计，各组命中数之和可能大于去重命中总数。
- 选股约 4.5 秒，页面有加载提示；MCP 间歇性"未找到"会自动重试。

> 想让这两个条件在指定时间自动推送到飞书？见[设计：归因定时推送](../architecture/DESIGN-scan-push.md)。

## 🔮 板块轮动分析

对当前强势板块做多角度 LLM 分析：并发行情采集 → 分批流式分析（进度条实时更新）→ 对抗审查 → 综合结论。页面为流式渲染，分批出结果，不用等全部完成。依赖 `LLM_API_KEY` 配置。

## 🛠️ 监控板块管理

- 左侧板块候选列表（最新成分股数 10~500 的板块才可选），右侧勾选保存；勾选即时生效到实时看板与全市场归类。
- 「刷新字典/成分股」按钮触发后台刷新（页面轮询进度），新上市板块需要刷新后才会出现。
- 勾选存于 `watched_concepts` 表；读取时仍会按最新成员数过滤——板块成分变化导致越界的会自动失效。

## 实时页为什么有时"卡在旧数据"？

- 看状态栏"刷新"时间戳：一直在更新说明轮询正常，只是上游分钟数据未变。
- 切换日期 / 模式后异常，可等一个轮询周期（3s）或手动刷新；后端在新分时序列写入后会立即淘汰旧结果缓存。
