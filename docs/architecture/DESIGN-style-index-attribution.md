# 三指数当日归因（高贝塔值 / 近期强势 / 同花顺热股）

> 状态：**设计定稿，待实现** | 数据源与归因算法已于 2026-09-12 全部实测验证；**归因口径已完成 2023-01~2026-09 回测（命题 2）：口径有效但增益小、时效仅 1 天，定位为当日解读工具**——结论详见[回测报告](../reference/STYLE-BACKTEST.md)及第八节

## 一、产品目的

盘中/盘后快速回答三个问题：

1. **今日风险偏好如何？** —— 高贝塔值（883926.TI）跌得比大盘多还是少，进攻资金在不在场
2. **前期的强势股阵营是否还在延续？** —— 近期强势（883409.TI）大幅回撤 = 获利盘集中出逃、风格切换信号
3. **散户注意力堆在哪里？** —— 同花顺热股（883910.TI）成分的表现 = 热钱/情绪温度计

再对每个指数做**成分股 → 概念板块归因**，定位"是谁把指数带崩/带起来的"：
例如热股指数 -2.35% 时，正贡献集中在数据中心(AIDC)/PCB/光伏，负贡献集中在乡村振兴 → 当日是"科技内部分化"而非全面退潮。

## 四、归因算法

### 第 1 层：指数概览（广度结构）

每指数一行：`官方涨跌幅 | 成分等权涨跌幅 | 上涨/下跌/涨停家数`。
三行对比即今日行情速览：如"高贝塔 -0.5% vs 近期强势 -3.0%" = 强势股补跌日。

### 第 2 层：概念归因排名（核心）

对指数内每只成分股 s（涨跌幅 r_s，等权份额 1/N），对其所属每个概念 c 累计贡献：

```text
contribution(c) = Σ_{s ∈ c ∩ index} r_s / N          # 暴露贡献：该概念标签下的成分股合计拉动了指数多少
hit(c)          = |{s ∈ c ∩ index}|                  # 命中数
lift(c)         = hit(c)/N ÷ (|c|/全市场数)          # 富集倍数：成分股对该概念的集中度
concept_chg(c)  = 概念指数 885xxx 自身当日涨跌幅      # 板块整体行情（含成分外的股票）
```

四列同看，避免单指标误读：
- contribution 大 + concept_chg 大 → 板块性行情，主线
- contribution 大 + concept_chg 小 → 仅指数内少数妖股带动，伪主线
- lift 高 + hit 高 → 该指数（如热股）注意力高度集中于该主题

### 第 3 层：成分股明细

成分股列表（涨跌幅排序），每股标注其贡献最大的 1~2 个概念，点击概念可跳转板块强度看板。

### 概念过滤（必须）

仅归到 `885` 开头概念，且命中以下任一规则即**不参与归因排名**：

1. **伪概念黑名单**：`融资融券`、`沪股通`、`深股通`、`中证500成份股`、`同花顺漂亮100`、`转融券标的`、`富时罗素概念`、`MSCI中国`、`标普道琼斯A股`、`深成500` 等通道/样本/风格标签（实测不过滤时负贡献榜被它们霸占）。规则：命中内置黑名单 + 命名模式（含"股通"/"融资融券"/"成份股"/"样本股"/指数名）即剔除。黑名单进 `config.py` 可维护。
2. **成分股数 > 150 的宽口径概念自动过滤**（2026-09-12 用户补充）：如 `机器人概念`/`华为概念`/`芯片概念` 等上千只成分的泛概念覆盖面过广，归因无指向性。阈值 `ATTRIBUTION_CONCEPT_MAX_MEMBERS = 150`（`config.py`），成分数取本地 `concept_members` 最新快照（`MAX(member_date)`）；快照中查不到的概念保守放行，并记日志便于发现字典缺口。

## 五、看板 Tab 设计

新增第 8 个 Tab"三指数归因"（路由 `/style_attribution`），布局自上而下：

```text
┌ 指数概览条：三张卡片（高贝塔值/近期强势/热股）
│   涨跌幅(大字) + 涨/跌/涨停家数 + 成分等权(交叉验证) + 轮换提示(成分较昨变动 n 只)
├ 指数切换器：三指数单选（默认同花顺热股）
├ 概念归因表：contribution | hit | lift | concept_chg 四列可排序
│   正/负贡献分色；点行展开该概念命中成分股
└ 成分股明细表：涨跌幅 | 现价 | 主要概念标签；点股票无跳转(或跳 THS 详情页)
```

交互口径：
- **实时模式**：3s 轮询，复用现有 dashboard 的状态栏/轮询控制；行情类请求打 `real_time_quotation`
- **历史模式**：日期选择器（交易日），成分用 p03473 历史日期、概念映射 `batch_get_stock_concepts(date)` 传历史日期、涨跌幅用 `cmd_history_quotation` 日 K —— 三接口均支持历史，链路成立
- 不做时间条拖拽/播放（该页是快照型归因，不是分时演进型；后续如需可接入 kline-fetcher 分时序列，见第九节）

## 八、口径有效性回测（命题 2，2026-09-13 用户确认范围）

**验证目标**：归因口径（contribution 排序 + 伪概念过滤 + 150 宽概念阈值）能否识别"有延续性的真主线"，而非当日噪声。

**窗口与数据**（已实测可行）：2023-01 至今（近期强势 2023 年中发布，此前仅两指数）。成分/概念映射/日K 全链路支持历史日期，point-in-time 无前视偏差。数据落独立库 `data/style_backtest.db`（不碰生产库）。

**检验设计**：

1. **延续性**：T 日 Top-K 概念 → T+k 日概念指数超额收益（相对当日全概念截面中位数），k=1/2/3/5；指标 = 平均超额 / 胜率 / rank-IC（T 日 contribution 排名 vs T+1 超额排名）
2. **消融矩阵**：过滤变体 {无 / 仅伪概念黑名单 / 黑名单+150} × 排序键 {contribution / hit / concept_chg} × K {3/5/10}——直接回答"过滤规则是否必要、哪个排序键最有效"
3. **安慰剂对照**：每日随机抽 K 概念（多种子）；归因日与行情日错位配对——排除市场 beta 与多重检验过拟合
4. **等权校验（顺带）**：全窗口逐日复算等权成分涨跌幅 vs 官方指数涨跌幅，检测指数编制变更

**已知近似（报告中明示）**：概念规模（150 过滤与 lift 用）取半年度快照就近回溯（约 8 个快照日 × 当期概念全集），非逐日精确；快照缺失的概念保守放行。

**脚本与产出**：`scripts/backfill_style_history.py`（一次性回填，约 9000 次 API 调用，断点续跑）→ `scripts/backtest_style_attribution.py` → 报告落 `data/style_backtest/report.md`（整理快照见[回测报告](../reference/STYLE-BACKTEST.md)）。**先报告后决策**：看结论再定是否把信号接进看板。

## 九、风险与注意

1. **成分轮换**：热股指数逐日换血，昨日归因结论不可直接外推今日；概览卡需展示"较昨变动 n 只"
2. **概念映射必须当日实时拉**：本地 `concept_members` 快照对三指数成分覆盖率仅 46%（且 `stock_concept_map` 现为空表），不能复用
3. **等权假设**：当前三指数实测等权成立；未来若从 107 族扩容新指数，需先验证"官方涨跌幅 ≈ 等权成分涨跌幅"，不等权则贡献分解口径要标注
4. **概念粒度**：885 概念有 293 个，成分股平均挂 10+ 概念，贡献天然稀释；排序看 contribution 时同时看 hit，低 hit（<3）的极端值降权处理
5. **盘中频率**：p03473 与概念映射虽按日缓存，首次拉取计入 2.4s 链路；3s 轮询只打行情接口（~0.5s/次），注意不要每轮重复拉成分
