# 股票集合题材催化反向归因系统

> 来源：用户方案书《股票集合题材催化反向归因系统需求说明书》v1.1（评审稿，2026-09-15），
> 本页为其项目化版本，内容与原方案书一致，并补充"与现有系统对照"一节。
> 定位：从"股票一起涨"反向识别"资金在交易什么"——对任意目标股票集合输出 1~3 个主驱动题材、
> 扩散题材与证据链。

## 一、背景与问题定义

一只股票通常同时归属多个行业、概念和主题标签。当某一批股票在某个交易日同步上涨时，业务人员
真正希望回答的不是"这些股票分别属于哪些概念"，而是"**这一批股票为什么一起涨，最可能由哪个
板块或题材催化**"。

传统做法按概念命中数量排序，容易被人工智能、新能源汽车、国企改革等大而宽的标签占据前列，
无法识别更具体、更具交易意义的驱动题材。例如：若"人工智能"命中 47 只、"机器人"命中 31 只、
"减速器"命中 22 只，单看命中数会优先选择人工智能；但如果减速器板块总成分仅 65 只、其中 22 只
进入强势股票池，则减速器对当日上涨的解释力可能显著更高。

**REQ-01 核心业务问题**：系统应对任意给定的目标股票集合 S，自动生成候选行业/概念题材，计算
其对目标股票共同上涨的解释能力，并输出 1~3 个最可能的主驱动题材及关联扩散题材。

**REQ-02 归因原则**：首版定位为"行情反向归因 + 消息证据验证"，不直接声称统计相关等同于严格
因果。系统需分别展示行情证据与消息证据，并形成可解释的综合置信度。

## 二、建设目标与范围

### 2.1 建设目标

- 从一批同步上涨或异动股票出发，在数秒级内定位最有解释力的行业/概念题材
- 降低宽泛概念、多重标签和高度重叠概念对判断的干扰
- 利用涨幅、实体涨幅、涨速、成交额、涨跌停结构、封板/炸板质量、连板梯队、异常强度及
  时间同步性识别真正被资金交易的题材
- 将行情识别结果与当日政策、行业事件、产品发布、涨价、订单、会议、公告等消息进行二次验证
- 输出可追溯的分项评分、命中股票、核心龙头、扩散路径和证据链，支持盘中决策与盘后研究

### 2.2 首版范围

| 范围项 | 首版处理 |
|---|---|
| 目标股票集合 | 外部直接传入股票代码集合；涨幅前 N、涨幅区间、成交额前 N、高贝塔成分、近期强势股等预定义股票池 |
| 分类维度 | 同花顺概念指数、二级行业、三级行业；行业与概念分开评分与展示 |
| 时间粒度 | 收盘后日频归因必选；具备分钟/快照数据时增加盘中同步性和启动时刻识别 |
| 催化验证 | 对 Top N 候选题材检索当日及邻近时段资讯，生成事件摘要和时间匹配度 |
| 输出 | Top 1~3 主驱动题材、Top 5 候选题材、命中股票、分项得分、重叠关系、龙头/跟随结构、涨跌停结构、消息证据 |

### 2.3 暂不纳入首版

- 自动下单或交易执行
- 仅依据大模型语义直接决定题材归属，而无行情与成分数据证据
- 对上市公司长期基本面因果关系进行归因
- 将题材评分直接等同于次日收益预测

## 三、核心业务场景

| 场景 | 输入示例 | 业务问题 | 主要输出 |
|---|---|---|---|
| 盘中异动识别 | 3~5 分钟内快速拉升的一批股票 | 资金突然在交易什么？ | 启动最同步的题材、异动时点、领涨股、扩散股 |
| 强势股归因 | 当日涨幅 7%~12% 的股票 | 今天强势股集中在哪条主线？ | 主线题材、解释覆盖率、题材纯度、Lift、板块异常强度 |
| 高贝塔股票池 | 指定高贝塔指数成分股 | 高弹性股票当前被哪个题材激活？ | 高贝塔内部主题聚集度、主线/支线 |
| 涨跌停/连板归因 | 昨日涨停、今日涨停、连板、跌停及炸板股票 | 极端强弱结构背后的共同题材是什么？ | 题材梯队、连板高度、封板率、炸板率、涨跌停比及风险扩散 |
| 盘后复盘 | 收盘后的全市场强势股票池 | 当日赚钱效应属于哪条题材主线？ | Top 题材及消息催化、主线强度与持续性观察项 |

## 四、术语与核心口径

| 术语 | 定义/建议口径 |
|---|---|
| 目标股票集合 S | 本次需要解释的股票集合（涨幅前 100、涨幅 7%~12%、某风格指数成分中的异动股等） |
| 候选题材 c | 至少命中目标股票集合中一定数量股票的行业或概念板块 |
| HitCount | \|S ∩ c\|，目标股票集合中属于题材 c 的股票数 |
| HitCoverage | HitCount / \|S\|，题材对目标股票集合的覆盖率 |
| ConceptPurity | HitCount / \|c\|，题材自身成分股中进入目标股票集合的比例 |
| BaselineRate | \|S\| / \|U\|，目标股票集合占股票基础全集 U 的比例 |
| Lift | ConceptPurity / BaselineRate，该题材股票进入目标集合的概率相对全市场提升倍数 |
| Synchronization | 题材命中股票在指定时间窗口内同步异动的程度 |
| AbnormalStrength | 题材当日收益、广度、成交活跃度等相对自身历史的异常程度 |
| LimitUpRate / LimitDownRate | 候选题材中涨停/跌停股票数占当日有效成分股比例；按证券、交易日实际涨跌幅限制规则判定 |
| SealRate / BreakRate | 封住涨停占触及涨停比例 / 触及涨停后未封住比例（涨停质量与分歧） |
| LimitBalance | (涨停数−跌停数)/(涨停数+跌停数+ε)，题材极端强弱平衡 |
| 主驱动题材 | 高解释力、高异常性、低冗余，并得到行情/涨跌停结构/消息证据支持的题材 |
| 扩散题材 | 与主驱动题材关联或成分重叠，但更宽泛、滞后启动或解释增量较低的题材 |

## 五、数据输入与依赖

- **REQ-03 股票基础全集**：统一维护可交易 A 股基础全集 U（BaselineRate、成分比例、全市场比较口径）。停牌、ST、北交所是否纳入由上层股票池规则配置，评分引擎不写死。
- **REQ-04 行业/概念成分映射**：目标日期有效的"股票-二级行业/三级行业/概念"多对多映射；概念成分尽量支持历史日期还原，仅提供当前成分时必须标记数据时点。
- **REQ-05 行情数据**：日频至少昨收/开/高/低/收/成交额/换手率；盘中模式需分钟或快照价格、成交额/量、涨速或可推导字段；需能获得或推导目标日期每只证券的涨停价、跌停价及适用规则。
- **REQ-06 板块行情**：候选行业/概念需具备当日及历史行情（收益、实体涨幅、强弱分位、ZScore、成交活跃度、历史异常强度）。
- **REQ-07 资讯数据**：题材关键词、发布时间、标题、正文/摘要、涉及公司/产业链实体。资讯能力暂不具备时不阻塞行情归因上线，但"消息证据"标记为未验证。
- **REQ-07A 涨跌停状态与规则**：按证券与交易日实际交易规则识别涨停、跌停、触及涨停、炸板、回封、连板等状态，不得统一写死为 10%。统计分母剔除停牌、无涨跌幅限制等不适用证券，保留判定规则版本。

首版优先复用现有 iFinD 概念/行业清单、股票归属映射及行情接口；具体接口、字段与历史日期能力以联调验证结果为准。

**复用关系**：

1. 现有 `GET /api/market/scan` 的知识图谱富集归类（lift 排序）≈ 本方案 P1 的

2. 预定义股票池中的"高贝塔成分、近期强势股"= [三指数归因](DESIGN-style-index-attribution.md)
   的 `STYLE_INDICES` 成分缓存（日级 p03473）直接复用。
3. 实体涨幅、涨速、首次异动时间等分钟级字段 = [开盘强势扫描](DESIGN-open-strength-scan.md)
   四维快照管线（`open_scan_engine`）复用。

**口径差异提示（需后续决策）**：三指数归因与开盘强势扫描采用的"宽概念硬过滤
（成分 >150 剔除）"与本方案 REQ-10/REQ-12 的"宽泛概念保留但经 Lift 降权、作为上位扩散标签
降级展示"存在口径冲突。三指数场景的硬过滤已被回测支持（用于窄主线排序）；题材归因场景按
方案书口径更优（宽概念承载扩散信息），建议本方案按 REQ-12 执行、不复用 150 硬过滤。

## 六、总体处理流程

1. 接收目标股票集合 S，记录股票池生成规则、数据日期、时间戳
2. 读取目标股票对应的二级行业、三级行业和概念映射，生成候选题材集合 C
3. 执行候选过滤：最小命中数、最小命中率、板块最小有效成分数、数据完整性校验
4. 分别计算覆盖度、纯度、Lift、上涨贡献、异常强度、同步性、涨跌停结构、龙头结构、流动性确认
   等指标；涨跌停结构同时在"目标命中股票"和"候选题材全体有效成分股"两个口径计算
5. 将各分项标准化到 0~100，计算 CatalystScore
6. 基于命中股票集合相似度进行概念聚类，压缩高度重叠的宽泛/近义概念
7. 使用"加权集合覆盖"从候选中选取 1~3 个主线题材，覆盖尽可能多的目标强势股，同时降低题材间冗余
8. 对 Top N 题材执行消息检索，比较消息发布时间与价格启动时点，形成消息证据评分
9. 输出主驱动、扩散题材、命中股票、分项评分、消息证据与置信度

## 七、候选题材生成

- **REQ-08 候选生成**：对 S 中每只股票展开所有有效概念/行业标签，按题材聚合命中股票，形成题材 c → 命中股票集合 Hc。行业与概念分层处理，不放在同一排行榜。
- **REQ-09 基础过滤**：默认候选需满足 HitCount ≥ 3；\|S\| 较小时可动态降低。对 HitCoverage 极低、ConceptPurity 极低且无明显板块异常的题材提前过滤。所有阈值可配置。
- **REQ-10 宽泛概念抑制**：不得仅按 HitCount 排序。对成分股规模特别大的宽泛概念，通过 ConceptPurity、Lift 和冗余压缩降低其天然数量优势。

## 八、题材解释力评分模型

首版采用可解释的规则评分：原始指标先在当日候选题材横截面或自身历史窗口标准化为 0~100，
再按权重合成 CatalystScore。权重为初始建议值，后续通过历史回测和人工复盘样本校准。

| 分项 | 建议权重 | 核心含义 | 示例口径 |
|---|---|---|---|
| 覆盖贡献 Coverage | 15% | 题材能解释目标股票集合中的多少股票 | HitCoverage，及按涨幅/成交额加权后的覆盖 |
| 题材纯度 / Lift | 18% | 该题材股票进入目标集合的概率是否显著高于全市场 | ConceptPurity、Lift；抑制宽泛概念 |
| 上涨贡献 Contribution | 17% | 题材命中股票贡献了多少实际上涨 | 命中股票收益、实体涨幅、成交额加权收益占 S 的比例 |
| 异常强度 AbnormalStrength | 13% | 题材今天是否相对自身历史突然变强 | 题材收益 Z20、上涨家数比例分位、成交活跃度分位 |
| 时间同步 Synchronization | 12% | 命中股票是否在相近时间共同启动 | 1/3/5 分钟窗口异动集中度、首次突破时间离散度 |
| 涨跌停结构 LimitStructure | 10% | 是否形成明显极端强弱聚集及封板质量 | 涨停/跌停比例、封板率、炸板率、连板高度、涨跌停平衡 |
| 龙头结构 LeaderStrength | 10% | 是否出现具有辨识度的核心领涨与跟随扩散 | 核心涨停/大涨龙头、连板梯队、龙一贡献与跟随扩散 |
| 流动性确认 Liquidity | 5% | 上涨是否获得成交行为确认 | 成交额、换手率、量比或相对活跃度 |

```text
CatalystScore = 0.15×Coverage + 0.18×LiftScore + 0.17×Contribution
              + 0.13×AbnormalStrength + 0.12×Synchronization
              + 0.10×LimitStructure + 0.10×LeaderStrength + 0.05×Liquidity
```

若盘中分钟/快照数据缺失，Synchronization 不参与计算，其 12% 权重按比例分配给 LiftScore、
Contribution、AbnormalStrength 与 LimitStructure；系统必须记录实际使用的权重版本。

### 8.1 Coverage 与上涨贡献

HitCoverage = HitCount / \|S\|。另可计算 ReturnContribution = Σ(w_i × Return_i)，i ∈ S∩c，
w_i 可采用等权、成交额权重或业务指定权重。同时保留数量口径和收益贡献口径，避免单一涨停股
扭曲整体判断。

### 8.2 ConceptPurity 与 Lift

示例：全市场 U 为 5000 只、目标强势股 S 为 100 只 → BaselineRate = 2%。某题材共 65 只股票、
其中 22 只进入 S → ConceptPurity = 33.8%、Lift ≈ 16.9，即该题材股票进入目标强势集合的概率
约为全市场平均的 16.9 倍。

### 8.3 异常强度

真正由事件催化的题材通常"相对自己过去突然变强"，不能只看当日绝对涨幅。建议组合题材收益 Z20、
上涨家数比例历史分位、成交额/换手活跃度历史分位；涨跌停家数及封板质量另设 LimitStructure
独立评分，避免重复计权。

### 8.4 时间同步性

盘中模式以首次快速拉升、突破指定涨幅、分钟涨速超阈值等事件时间为基础，对同一题材命中股票
计算 1/3/5 分钟窗口的共同启动比例及启动时间离散度。多只股票在极短时间内共同异动且共享某一
较具体概念时，该概念的催化解释力显著提升。

### 8.5 涨跌停结构因子

涨跌停是题材强弱最直接的极端状态信号。该因子必须同时从**目标股票集合命中股票**和**候选题材
全部有效成分股**两个口径计算——目标股票池构造可能天然排除涨停股（如目标池仅选涨幅 5%~9% 的
股票，而真正的板块龙头已涨停），只看 S∩c 会漏掉最强的题材确认信号。

| 指标 | 建议口径 | 归因含义 |
|---|---|---|
| LimitUpCount / LimitUpRate | 题材有效成分中收盘涨停家数及比例 | 涨停集中度越高，题材极端强势扩散越明显 |
| LimitDownCount / LimitDownRate | 题材有效成分中收盘跌停家数及比例 | 跌停扩散是负向证据；与涨停并存提示高分歧 |
| TouchLimitUpCount | 盘中触及涨停的股票数 | 识别曾出现极端资金冲击但未必最终封住的股票 |
| SealRate | 收盘封住涨停数 / 盘中触及涨停数 | 封板率越高，题材一致性和承接质量通常越强 |
| BreakRate | 炸板股票数 / 盘中触及涨停数 | 炸板率上升代表分歧、抛压和持续性风险 |
| ReSealRate | 炸板后再次回封并收盘封住的比例 | 识别强承接与盘中分歧后的修复 |
| MaxBoardHeight | 题材内当日最高连续涨停板数 | 反映题材空间高度和核心龙头辨识度 |
| BoardLadder | 首板/2板/3板及以上的家数结构 | 梯队越完整，越说明存在从龙头到跟随的扩散 |
| LimitBalance | (涨停数−跌停数)/(涨停数+跌停数+ε) | 极端强弱归一化；接近 1 偏强，接近 −1 偏弱 |

LimitStructure 先由上述指标标准化后组合，不直接用单一"涨停家数"决定排名。对成分股数量差异
较大的概念，优先采用比例、历史分位和相对全市场基准，避免大板块天然占优。

判定涨跌停必须使用证券在目标交易日实际适用的价格涨跌幅限制规则，处理不同板块、风险警示证券、
新股/特殊交易日等差异；无涨跌幅限制、停牌或数据异常证券不进入相应比例分母。

**负向处理**：当题材 LimitDownRate、BreakRate 明显上升，或"高涨停+高跌停/高炸板"同时出现时，
不应简单判为强催化，应降低 LimitStructure 得分并标记"高分歧/退潮风险"。

## 九、重叠概念压缩与主线提取

同花顺概念之间可能存在近义、上下游或大范围成分重叠，但不存在可直接使用的严格父子层级。首版
基于"命中股票集合相似度 + 题材自身强度"构建数据驱动的重叠关系，不依赖人工维护概念树。

- **REQ-11 概念相似度**：Jaccard(Hc1, Hc2) = \|Hc1∩Hc2\| / \|Hc1∪Hc2\|，默认 ≥ 0.70 视为高度重叠候选（可配置）。
- **REQ-12 簇内代表题材**：高度重叠题材进入同一簇后，优先选择 CatalystScore 高、Lift 高、题材规模更聚焦且当日异常性更强的题材作为"代表题材"；宽泛概念作为上位扩散标签保留但降级展示。
- **REQ-13 最小主线集合**：从压缩后的候选中选择不超过 3 个主驱动题材，用加权集合覆盖：最大化已解释股票的上涨贡献与覆盖率，同时对题材数量和两两重叠度施加惩罚。

默认目标：1~3 个主线题材合计解释目标股票上涨贡献的 60%~70%；无法达到时明确输出
"题材分散/无单一主线"，不得强行归因。

## 十、消息催化验证

- **REQ-14 Top N 资讯检索**：仅对行情评分 Top N（建议 5~10）题材执行资讯验证。关键词包含题材名称、核心产业链词、代表公司名及高频共现实体。
- **REQ-15 时间一致性**：记录消息发布时间 T_news 与题材/核心股票首次明显异动时间 T_move。消息在异动前发布且时间距离较近时提高证据分；明显晚于行情启动时仅作事后解释。
- **REQ-16 消息分类**：至少区分政策、产业事件、产品发布、价格变化、订单/招标、会议/展会、海外映射、公司公告、市场传闻等类型，标记来源可靠性。
- **REQ-17 综合置信度**：同时展示"行情解释度"和"消息证据度"，综合判断分高/中/低置信度：

| 行情证据 | 消息证据 | 建议判断 |
|---|---|---|
| 高 | 高 | 高置信度核心催化题材 |
| 高 | 低/无 | 高概率资金主线，消息原因待确认 |
| 低 | 高 | 有消息但市场响应有限，不判定为核心驱动 |
| 低 | 低 | 非主线/标签重叠 |

不因缺少消息而否定明显的行情聚集，也不因存在新闻而忽略板块未响应的情况。

## 十一、输出与展示

**REQ-18 主结果卡片**：主界面优先展示 Top 1~3 主驱动题材（不先展示几十个股票标签）。每个主线
展示 CatalystScore、行情证据、消息证据、HitCount/HitCoverage、Lift、题材涨幅、同步性、
涨停/跌停家数与比例、封板率/炸板率、连板高度、核心龙头和一句话判断。展示示例（非实际市场结果）：

| 排名 | 题材 | 解释度 | 命中 | Lift | 异常强度 | 同步性 | 角色 |
|---|---|---|---|---|---|---|---|
| 1 | 减速器 | 87 | 22 | 16.9x | 99 | 91 | 核心催化 |
| 2 | 机器人 | 74 | 31 | 8.4x | 93 | 82 | 主线扩散 |
| 3 | 工业母机 | 51 | 14 | 5.2x | 78 | 60 | 关联题材 |
| 4 | 人工智能 | 38 | 47 | 1.6x | 67 | 32 | 宽泛标签 |

**REQ-19 股票明细**：点击题材后展示命中股票（代码/名称、当日涨幅、实体涨幅、成交额、首次异动
时间、涨跌停状态、连板数、题材内角色、同时命中的其他高分题材）；另列出**不在目标股票池但属于
该题材的关键涨停/跌停股票**作为确认或风险证据。

**REQ-20 重叠关系**：展示主线与扩散题材的成分重叠与新增解释量（如"减速器命中 22 只，其中 19
只同时属于机器人；机器人新增解释 9 只目标股票"）。新增解释量是保留扩散题材的重要依据。

**REQ-21 证据链**：每次结果保存股票池定义、数据日期、候选题材列表、分项原始值、标准化值、
权重版本、消息证据和最终排名，支持复盘与回测。

## 十三、非功能需求

| 编号 | 要求 |
|---|---|
| NFR-01 性能 | 收盘后对 100~300 只目标股票完成纯行情归因 ≤ 5 秒（不含资讯检索）；盘中增量更新 ≤ 2 秒 |
| NFR-02 可解释性 | 所有总分必须可拆解到分项指标，不允许仅输出黑盒标签 |
| NFR-03 可配置 | 最小命中数、相似度阈值、历史窗口、分项权重、主线数量、资讯 Top N 等参数可配置并版本化 |
| NFR-04 可回放 | 任意历史交易日可用当日数据重新计算，避免未来成分泄漏；历史成分不可得时显式标记限制 |
| NFR-05 数据质量 | 对缺失值、停牌、无涨跌幅限制证券、涨跌停价异常、成分映射异常、题材行情缺失、时间戳异常校验并记录 |
| NFR-06 稳定性 | 单个题材或单只股票数据异常不得导致整批任务失败；降级后需在结果中标记 |
| NFR-07 安全 | 认证信息通过运行环境安全注入，日志与结果表不保存令牌、密钥等敏感字段 |

## 十四、验收标准

| 验收项 | 通过标准 |
|---|---|
| 股票集合输入 | 可对指定股票代码集合及至少 3 类预定义股票池执行归因 |
| 候选生成 | 目标股票关联的行业/概念可完整聚合，结果可追溯到股票明细 |
| 宽泛概念抑制 | 构造的"大概念高命中、细分概念高纯度"样例中，不会仅按命中数把宽泛概念固定排第一 |
| Lift 计算 | 随机抽样人工复算 HitCoverage、ConceptPurity、BaselineRate、Lift 与系统一致 |
| 异常强度 | 能使用历史窗口识别题材当日相对异常，而非仅展示绝对涨幅 |
| 涨跌停判定 | 随机抽样不同证券类型和历史交易日，涨停/跌停/触板/炸板状态与实际适用交易规则一致，不以固定 10% 阈值替代 |
| 涨跌停结构 | 候选题材可输出涨停/跌停家数与比例、封板率、炸板率、连板高度及 LimitBalance；目标池外的题材涨停龙头仍可作确认信号 |
| 负向风险 | 跌停或炸板显著扩散时，LimitStructure 形成负向影响并显示高分歧/退潮风险 |
| 同步性 | 有分钟数据时可识别共同启动时间窗口并输出同步性分数 |
| 重叠压缩 | 高度重叠概念能够聚类，主结果默认不重复展示多个几乎同义题材 |
| 主线提取 | 默认输出 ≤3 个主驱动题材；无明显集中时可输出"无单一主线" |
| 消息验证 | Top 题材可关联资讯并显示消息时间与行情启动时间关系；资讯不可用时正常降级 |
| 结果可解释 | 任一 CatalystScore 可追溯到原始指标、标准化值和权重版本 |
| 性能 | 满足 NFR-01 或形成明确的性能基线与优化清单 |

## 十五、实施阶段与后续扩展

| 阶段 | 建议交付 |
|---|---|
| P0 数据验证 | 验证股票-概念/行业映射、历史成分、板块日线、股票分钟/快照、涨跌停价与交易规则、触板/炸板/连板状态、资讯检索的可用范围与字段（大部分项见第五节对照表，已有实测结论） |
| P1 盘后 MVP | 候选生成、Coverage/Purity/Lift、上涨贡献、异常强度、涨跌停结构、规则评分、Top 题材输出 |
| P2 重叠压缩 | Jaccard 聚类、增量覆盖、1~3 个最小主线集合 |
| P3 盘中识别 | 接入分钟/快照，增加启动时刻、涨速、同步性、龙头扩散路径 |
| P4 消息证据 | 接入资讯，对 Top N 题材完成事件抽取、发布时间对齐与综合置信度 |
| P5 学习型模型 | 积累人工确认样本后，用排序学习/分类模型学习分项权重；规则分与模型分分开展示 |

首版先完成 P0~P2，在不依赖复杂新闻理解和盘中分钟数据的情况下，先解决"股票集合 → 最可能主线
题材"的核心问题。该模块随后可作为市场情绪/概念赚钱效应系统的一个独立归因服务复用。
