# 开盘强势扫描（9:30~9:40 四维判断）

> 状态：**设计定稿，待实现** | 四个指标的数据可用性已核对（2026-09-13），口径经用户确认

## 一、产品目的

开盘后 10 分钟内，对**三指数当日成分股**（高贝塔值/近期强势/同花顺热股，去重约 170~210 只）
基于四维数据快速判断：

1. **哪些个股在强势上涨**（区分"竞价高开真承接"与"高开低走假强势"）
2. **哪些关联概念板块在开盘走强**（强势股集中在哪些主题 → 当日主线的开盘验证）

与[三指数归因](DESIGN-style-index-attribution.md)互补：彼者是全天/任意时刻的归因视角，
本页是开盘 10 分钟的**时效性窗口**视角——开盘量能爆发 + 实体承接是当日主线最早的可验证信号。

## 二、关键决策记录（2026-09-13 用户确认）

| 决策点 | 结论 |
|---|---|
| 股票池 | **仅三指数当日成分并集**（不做全市场初筛；成分每日 p03473 一次，复用三指数归因 Tab 的成分缓存） |
| 量能基线 | **过去 5 个交易日同期（9:30~当前时刻）累计成交量均值** |
| 产出形态 | 看板新 Tab"开盘强势" |

## 三、四维指标（三有其一新）

数据源统一走 kline-fetcher 分时（`pre_market` + `trading` 序列），不混用 iFinD 快照，避免口径拼接。

| 指标 | 定义 | 来源 | 状态 |
|---|---|---|---|
| 竞价涨幅 `auc_chg` | (竞价开盘价 − 昨收)/昨收，取 `pre_market` 末点 ref_price | 分时序列 | auction_engine 已有同口径因子 |
| 涨速 `speed` | 1min 滚动涨速 + 涨速加速（▲/▼） | 分时序列 | stock_scorer 已有 |
| 实体涨幅 `body` | (last − open)/open，open = 竞价开盘价 | 分时序列 | stock_scorer 已有 |
| 量能比 `vol_ratio` | 今日 9:30~t 累计量 ÷ 过去 5 日同期累计量均值 | 分时序列 + 5 日历史分时 | **需新算** |

涨停判定沿用 stock_scorer 规则（主板 9.8 / 创业科创板 19.5 / 北交 29），**涨停股直接置顶强势榜**
（封板 = 开盘最强形态），不参与 z-score 混合。

### 综合分

对股票池横截面做 z-score 标准化后加权（`config.OPEN_SCORE_WEIGHTS` 可调）：

```text
opening_score = 0.20×z(auc_chg) + 0.25×z(speed) + 0.30×z(body) + 0.25×z(vol_ratio)
```

权重设计意图：竞价涨幅是"先天定位"权重最低；实体涨幅是开盘承接的核心证据权重最高。
z-score 在股票池内标准化，天然适配成分轮换（池子变化不影响分数可比性）。

## 四、板块关联（强势板块榜）

强势股（`opening_score` Top 或超阈值）→ 概念映射 → 板块开盘强度。

- 概念映射：`batch_get_stock_concepts` 当日一次（~3 次调用，日级缓存），**沿用三指数归因的
  过滤口径**（885 前缀 + 伪概念黑名单 + 150 宽概念阈值）
- 板块开盘强度（config 可调）：

```text
board_score = 命中强势股的 opening_score 均值 × log2(1 + hit)
board_chg   = 概念指数当日实时涨跌幅（iFinD real_time_quotation，概念代码一次批量）
```

榜单展示：概念名 / 命中数 / 平均分 / 板块指数实时涨幅；与三指数归因 Tab 的概念表联动跳转。

## 五、引擎与刷新节奏

| 时段 | 动作 |
|---|---|
| 9:26~9:28（盘前一次） | 拉当日三指数成分（p03473）+ 概念映射 + **过去 5 交易日分时**（~200 只 × 5 天，32 线程约 1~2 分钟，日级缓存至日切） |
| 9:30~9:40 | 每 **30s** 自动刷新：拉成分股当日分时（~200 只一轮 <5s）→ 切片到当前时刻 → 四维分 |
| 9:40 后 | 冻结末次快照，页面停留复盘；时间条可拖回 9:30~9:40 任意时刻重算（纯内存切片，毫秒级） |
| 历史模式 | 传日期：该日成分 + 该日概念映射 + 该日分时（全天拉取后截取 9:30~9:40 窗口），全部接口支持历史日期，与三指数归因 Tab 同法 |

刷新 30s 而非看板默认 3s：本页观察的是分钟级形态（涨速/量能累积），3s 刷新无信息增量且徒增拉取压力。

## 八、风险与注意

1. **量能单位一致性**：vol_ratio 分子分母同源（kline-fetcher 分时 volume），自比天然一致；
   实现时核对累计口径（9:30~t 的逐分钟累加）
2. **昨日/5 日前成分内的新股与停牌股**：无历史分时的股票 vol_ratio 置空并降权（不置 0，避免误判缩量）
3. **一字板无量股**：竞价涨幅 9.8%+ 但量能比可能极低（无量一字），综合分靠 body/speed 也趋 0——
   由涨停置顶规则兜底，不进 z-score 扭曲分布
4. **窗口期成分变动**：三指数成分日间轮换，9:26 拉取的成分即当日口径；热股指数换血快，
   页面顶部展示"较昨变动 n 只"
5. **9:20~9:25 撤单窗口陷阱**：竞价因子若未来要前移到 9:20 观察，须注意 auction_engine 已论证的
   不可撤单窗口（9:20 后）才反映真实意图——本设计取 9:25 末点，无此问题
6. **历史 pre_market 退化（实测）**：kline-fetcher 历史分时的集合竞价序列多为单点，
   竞价涨幅的历史口径必须走"日K昨收 + 分时首分钟价"的退化路径（open_scan_engine 已实现），
   实时模式（当日）无此问题

## 九、落地路径

## 十、自适应权重（滚动 IC 学习，2026-09-13 用户确认）

**动机**：四维固定权重无法适应市场状态切换（如某阶段竞价涨幅失效）。权重改为"滚动窗口内
各维度真实预测力"的学习输出，目标函数 = **当日 9:40→收盘涨幅**（T 日快照拟合，T 日当天
可验证、9:40 仍可操作）。

### 算法（IC 法，回归法留作后续对照）

```text
每日收盘后：IC_i(T) = spearman(z_i(9:40快照), 当日9:40→收盘涨幅)   # 池内横截面
滚动窗口 N=60 日：IC_IR_i = mean(IC_i) / std(IC_i)，t_i = mean/std×√N
w_IC,i  ∝ max(IC_IR_i, 0)          # 仅取正且显著（t_i ≥ 2）的维度
w(T+1) = α·w_IC + (1−α)·等权       # 收缩 α=0.5，防 IC 噪声
```

更新频率**周级**（非日级，防权重抖动毁掉可解释性）；无显著维度时整体退回等权。
页面展示当前权重 + 各维度滚动 IC/t 值（透明可审计）。

### 验证协议（防过拟合，复用命题 2 纪律）

walk-forward：T 日仅用 `[T−N, T−1]` 拟合权重 → T 日评估 Top-K 前瞻收益超额（相对池内中位数）
与胜率，对照组 = 固定权重（0.2/0.25/0.3/0.25）与随机权重（多种子）。学习权重打不过固定权重
则退回等权并告警。

### 工程落点

| 组件 | 说明 |
|---|---|
| `data/open_scan.db` 表 `snapshot` | (trade_date, stock_code, p940, auc_chg, speed, body, vol_ratio, fwd_ret)；回填历史 + 每日 9:40 冻结自动落库（后续 P1 接入） |
| `open_scan_engine.py` | 四维快照计算（纯函数，分时序列 → 维度值），回填/实时/历史三场景共用 |
| `scripts/backfill_open_scan_history.py` | 历史分时回填：~200 只 × 120 交易日（成分口径复用 style_backtest 库 bt_member，point-in-time） |
| `scripts/open_weight_learner.py` | IC 学习 + walk-forward 验证，产出 `weights.json`（引擎消费）与诊断报告 |

现实预期：~200 只横截面的日度 IC 噪声不小，动态权重的目标是**及时降权失效维度**（防恶化），
不是榨 alpha。

### 首轮结果（2026-09-13，120 交易日 walk-forward）

| 维度 | IC 均值 | t 值 | 结论 |
|---|---|---|---|
| 竞价涨幅 | -0.014 | -1.1 | 无预测力 |
| 涨速 | -0.013 | -1.1 | 无预测力 |
| 实体涨幅 | -0.014 | -1.2 | 无预测力 |
| 量能比 | -0.003 | -0.3 | 无预测力 |

四个维度对"当日 9:40→收盘"均无稳定预测力，学习权重/固定权重/随机权重的 Top-K 前瞻超额
处于同一噪声带（0~0.25%，胜率≈50%）。**学习器按门控退回等权**——这正是 walk-forward
门控的设计目的：防止把噪声学进权重。

因此综合分的定位明确为**描述性排序工具**（把开盘强势股按多维证据排出来供人判断），
不是收益预测器。学习器保留为周级监控：某维度 IC 若显著转正（市场状态变化）自动启用并提示。

**数据工程教训（已修复）**：kline-fetcher 历史分时的 `pre_market` 序列基本退化（单点），
直接取"末点 ref−首点 ref"会得到 97% 假平开，并与巨大并列块交互产生 +0.48 的伪 IC。
修复口径：昨收取日K前一交易日收盘、开盘价退化回退为分时首分钟价、当日收盘用分时末点
（同源，同时消除前复权错位）。见 `open_scan_engine.py` 注释。
