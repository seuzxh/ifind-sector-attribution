# 架构与设计

本章节面向需要读懂代码或改造系统的开发者：整体架构、核心算法口径、各功能模块的设计取舍。

## 推荐阅读顺序

1. **架构总览（V2 现行）**：当前系统的分层结构与数据链路，新读者从这里开始。
2. **架构设计（V1 历史）**：早期版本的实现记录，保留用于理解演进脉络，部分内容已过时。
3. **前端架构**：Vue 3 SPA 的目录结构、状态管理与轮询机制。
4. 各功能模块设计文档：强势归类扫描、归因定时推送、监控板块管理、知识图谱（规划中）。

## 快速定位

| 想了解 | 看哪篇 |
|---|---|
| daily / realtime 两条数据链路的差异 | 架构总览（V2 现行） |
| 板块强度三维评分、多周期融合、L1 归因算法 | 架构总览（V2 现行） |
| 双概念编码体系（行业码 vs 概念板块码） | 架构设计（V1 历史） |
| 前端 Tab 如何组织、接口如何封装 | 前端架构 |
| 强势归类两页的选股与归类逻辑 | 设计：强势归类扫描 |
| 飞书定时推送的触发与卡片结构 | 设计：归因定时推送 |
| 监控板块的勾选持久化与成员数门槛 | 设计：监控板块管理 |
