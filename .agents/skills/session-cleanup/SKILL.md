# 会话收尾自查

## 步骤

1. **临时产物检查**：运行 `git status --porcelain` 列出全部变更，逐一确认：
   - 无调试脚本、临时验证文件（*.bak、test_tmp*、scratch/ 下未清理内容）遗留
   - 无 console.log / print 调试输出残留在业务代码中
2. **死代码检查**：本次会话新增的函数/组件，确认均被引用；未被引用的删除或说明保留原因
3. **测试验证**：跑完整测试套件（按 AGENTS.md 常用命令），贴出输出作为证据
4. **提交规范**：提交信息符合 Conventional Commits；一次提交只做一件事
5. **收尾报告**：用 3-5 行总结本次会话：改了什么、为什么、留下什么待办

## 边界情况
- 若发现遗留临时文件较多，先全部清理再继续
- 测试失败时不允许跳过，修完或明确说明阻塞原因
